TikTok Video Scheduler

TikTok Video Scheduler is a desktop application that helps creators queue and auto-publish their own original MP4 videos to their authorized TikTok account via the official TikTok Content Posting API (Direct Post).

How it works: Users authorize via TikTok OAuth (video.publish scope), add videos with captions, set a date/time, and the app publishes at the scheduled time using FILE_UPLOAD.
